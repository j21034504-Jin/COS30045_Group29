# Different Roads, Different Risks

## COS30045 Data Visualisation Project — 2026

### Project Overview
This project investigates trends in hospitalised injuries resulting from road traffic crashes in Australia between 2011 and 2021.

The aim is to develop an interactive data visualisation website that communicates meaningful patterns across different road-user categories, including car drivers, motorcyclists, pedal cyclists and pedestrians.

### Data Source
Bureau of Infrastructure and Transport Research Economics (BITRE).

Dataset: [Hospitalised Injury Data](https://www.bitre.gov.au/resource/road-safety/hospitalised-injury)

### Research Questions
1. How have hospitalisations from road crashes changed between 2011 and 2021?
2. How do hospitalisation trends differ between road-user categories?
3. Which road-user categories show the most significant changes over time?
